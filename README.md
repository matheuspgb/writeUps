### 🔐 Writeups - Pentest Web

Este repositório reúne os writeups e as anotações dos laboratórios que resolvo durante meus estudos de segurança ofensiva, com foco em aplicações web. Ele nasceu durante o **Web Penetration Tester Path** da Hack The Box Academy, que já concluí, e agora também passa a documentar os labs da **PortSwigger Web Security Academy**, que sigo praticando de forma contínua.

O objetivo é registrar o raciocínio por trás de cada exploração (reconhecimento, identificação da falha, exploração e lições aprendidas), servindo como material de consulta pessoal e como portfólio público da minha evolução na área.
